# iパス毎日10問

ITパスポート試験の学習用Webアプリ（スマホ向け・PWA）です。サーバ不要で、学習記録はスマホのブラウザ内に保存されます。

## 機能

| 機能 | 内容 |
|---|---|
| 今日の10問 | 毎日日付ごとに10問を自動選出。途中でアプリを閉じても続きから再開できます |
| リマインド | スマホのカレンダー（.ics / Googleカレンダー）に「毎日◯時」の予定と通知を登録。アプリを開いたとき未完了ならホームにも表示 |
| カウントダウン | 受験日までの残り日数と、全問に到達するための1日あたりのペース |
| 到達率・予想スコア | 9つの大分類ごとの到達率、3分野＋総合の予想スコア（1000点満点、合格ライン 総合600・各分野300） |
| 苦手問題の復習 | 間違えた問題は翌日以降に自動で再出題（間隔反復）。解説一覧、★苦手マーク、苦手だけの演習、分野別演習 |
| その他 | オフライン動作、ダークモード、学習データのバックアップ／復元、問題の追加 |

## 問題について

| 種類 | 問題数 | ファイル |
|---|---|---|
| IPA公開の過去問題（令和6・7・8年度 公開問題） | 300問 | `js/past_questions.js`（図表は `img/past/`） |
| オリジナル類似問題（シラバスの9大分類に沿って作成） | 132問 | `js/questions.js` |

- 本番の出題比率（ストラテジ35：マネジメント20：テクノロジ45）に合わせて出題されます。
- 「設定 → 出題範囲」で「すべて／過去問だけ／オリジナルだけ」を切り替えられます。
- 過去問は本番どおりの選択肢の順番で表示します（オリジナル問題は毎回シャッフル）。

### 過去問題の出典と解説

- 出典：独立行政法人情報処理推進機構（IPA）ITパスポート試験 公開問題。各問題に「令和◯年度 ITパスポート試験 公開問題 問N」と表示しています。
- 問題文・選択肢・正解は、IPAが公開している問題冊子と解答例によります。問題冊子は画像のPDFだったため、OCR（文字認識）で読み取り、誤読を1問ずつ画像と照合して修正しました。
- **解説はこのアプリ独自に作成したもの**です（IPAは解説を公開していません）。
- 図表が必要な問題（27問）は、問題冊子から図表部分を切り抜いて表示しています。

### 過去問題を年度ごとに追加する（開発者向け）

`tools/ipa/` に変換ツールがあります。新しい年度のPDFを入手したら、次の順に処理します。

1. `pdfimages -j <問題冊子.pdf> rXX/p` でページ画像を取り出し、`pdftotext -layout <解答例.pdf> rXX_ans.txt` で解答を取り出す
2. `ocr.sh` … 日本語OCR（Tesseract）でページを読み取る
3. `parse.py rXX` … 1問ずつに切り分け、図表を切り抜く
4. `structure.py rXX` … 問題文と選択肢ア〜エに分ける
5. `fix_rXX.txt` … 誤読の修正・大分類・解説を書く（記法はファイル先頭を参照）
6. `apply.py <リポジトリ>` … `js/past_questions.js` と `img/past/` を作り直す

### 問題をアプリから追加する

次の形式のJSONファイルを作り、アプリの「設定 → 問題を追加する」から読み込むこともできます（追加した問題はそのスマホ内だけに保存されます）。

```json
[
  {
    "id": "MY-001",
    "f": "S",
    "c": "企業と法務",
    "q": "問題文",
    "ch": ["選択肢ア", "選択肢イ", "選択肢ウ", "選択肢エ"],
    "a": 2,
    "ex": "解説",
    "src": "令和6年度 ITパスポート試験 問1"
  }
]
```

- `f`：`S`（ストラテジ系）/ `M`（マネジメント系）/ `T`（テクノロジ系）
- `c`：大分類（企業と法務・経営戦略・システム戦略・開発技術・プロジェクトマネジメント・サービスマネジメント・基礎理論・コンピュータシステム・技術要素）
- `a`：正解の番号（0=ア, 1=イ, 2=ウ, 3=エ）

## スマホで使う（GitHub Pages で公開）

1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** をこのアプリのブランチ・`/ (root)` にして **Save**
3. 数分後に表示されるURL（`https://<ユーザー名>.github.io/I-pass/`）をスマホで開く
4. **ホーム画面に追加**（iPhone：Safariの共有ボタン → ホーム画面に追加 ／ Android：Chromeメニュー → アプリをインストール）
5. アプリの「設定」で受験日とリマインド時刻を設定し、カレンダーに登録

※ 非公開（private）リポジトリで GitHub Pages を使うには有料プランが必要です。

パソコンで試すだけなら、このフォルダで `python3 -m http.server` を実行し、`http://localhost:8000` を開きます。

## しくみ（計算方法）

- **毎日の出題**：日付を「種」にした乱数で選ぶので、同じ日に何度開いても同じ10問になります。
  期限が来た苦手問題を最大4問入れ、残りは「未回答」「到達率の低い分野」を優先した重み付きランダムで選びます。
- **間隔反復**：正解するたびに次の出題までの間隔を 1→3→7→14→30日 と伸ばし、間違えたら翌日に戻します。
  間違えた問題は **2回連続で正解** すると「克服」として苦手リストから外れます。
- **到達率**：分野内の全問題のうち、2回以上連続正解＝1問、直近1回正解＝0.5問として数えた割合。
- **予想スコア**：分野ごとに「各問題の直近の正誤」から正答率を推定（回答数が少ないうちは50%に寄せる）し、本番の出題数で重み付けして1000点満点に換算した参考値です。実際の試験はIRT（項目応答理論）で採点されるため、目安として使ってください。
